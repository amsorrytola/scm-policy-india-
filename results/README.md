# Results

All analysis outputs for the Bihar prohibition study live here. Files are
generated by the notebooks in `notebooks/` and (for figures) the scripts
in `scripts/`. Everything is regenerable end-to-end from
`data/processed/bihar_panel.csv`.

```
results/
├── figures/   # PNG figures embedded in the notebooks, slides, and website
├── tables/    # Headline-numbers CSV
└── logs/      # Run logs (pip installs, ad-hoc diagnostics)
```

The interactive website pulls from `api/results/*.json` (precomputed
JSON snapshots), not from this directory. See `api/results/` notes
at the end of this file.

## `figures/` — 19 PNGs

### EDA (Notebook 01)
| File | Description |
|---|---|
| `eda_bihar_all_units.png` | Spaghetti plot — all 14 donors + Bihar's road-accident-death trajectory, 2010-2022. Bihar drawn in navy, donors in light gray. Treatment year marked with vertical line. |

### SCM — Primary outcome: road accident deaths (Notebook 05)
| File | Description |
|---|---|
| `scm_bihar_main.png` | Bihar (actual) vs Synthetic Bihar over 2012-2022. Pre-period RMSPE = 42 deaths; post-period gap reverses sign by 2018. |
| `scm_bihar_gap.png` | Treatment-effect plot: Bihar − Synthetic Bihar, year by year. Negative 2016-2017 (lives saved), positive 2018-2022 (effect reverses). |
| `scm_bihar_placebo.png` | In-space placebo: each donor as if treated. Bihar's gap (navy) stands out against placebo gaps (gray). RMSPE ratio rank: 2 of 14, permutation p ≈ 0.071. |
| `scm_bihar_loo.png` | Leave-one-out robustness. 13 LOO refits; the synthetic Bihar trajectory is stable across donor exclusions. No single donor drives the result. |

### SCM — Secondary outcome: own tax revenue (Notebook 05, Section 7)

|---|---|
| `scm_bihar_tax_main.png` | Bihar own-tax revenue vs synthetic. Post-treatment gap of approximately −₹2,017 Cr/yr — attenuated proxy for excise loss because non-excise taxes (GST compensation, stamps, vehicle tax) grew strongly post-2016. |

### SCM + BSTS — Third outcome: NSDP per-capita YoY growth (Notebook 07)
| File | Description |
|---|---|

| File | Description |
|---|---|

## Regenerating everything

```bash
# Activate venv first
source venv/bin/activate

# 1. EDA + main SCM analysis
jupyter nbconvert --to notebook --execute --inplace notebooks/01_eda_bihar.ipynb
jupyter nbconvert --to notebook --execute --inplace notebooks/05_scm_bihar.ipynb

# 2. Growth outcome (third SCM + BSTS)
jupyter nbconvert --to notebook --execute --inplace notebooks/07_scm_bihar_growth.ipynb

# 3. BSTS for primary + tax outcomes
jupyter nbconvert --to notebook --execute --inplace notebooks/09_bsts_bihar.ipynb

# 4. Robustness
jupyter nbconvert --to notebook --execute --inplace notebooks/10_robustness_bihar.ipynb

# Or regenerate just the polished BSTS figures:
python scripts/regenerate_bsts_figures.py
```

Each notebook re-saves its result JSONs into `api/results/` and its
PNGs into `results/figures/`. The website picks up the JSONs on next
API restart.

## Note on `api/results/`

regenerated by the same notebooks listed above (via `scm.save_json()`
